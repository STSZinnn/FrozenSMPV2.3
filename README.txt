FROST PLUGIN v2.3 - Paper Minecraft Java 1.21.11

Retains all v2.2 weapons and permissions/trust system.

NEW ITEMS (OP-only /frost menu):
Frozen Spear of Ice Spikes (Netherite Spear) - right click to throw a visual
spear at the ground and create 8 sequential spikes. Each enemy can take
1.5 hearts per cast and receives upward launch. 30-second default cooldown.

Frozen Totem of Winter's Blessing - right-click for a 12-second moving
10-block aura; Regeneration I for the owner/trusted people, Weakness I for
other players. 45-second default cooldown. Doesn't resurrect on death.
Normal Minecraft inventory-drop rules determine whether the totem drops.

New utility-item copies have the Unbreaking III enchantment and a glint.

Settings are editable under /frost config or in
plugins/PunchSnowball/config.yml (/frost reload to refresh file edits).

GITHUB BUILD:
Keep .github/workflows/build.yml from this ZIP. If Windows hides
.github, create or edit the workflow in GitHub's web editor.
Actions > Build Frost Plugin > Run workflow; download the JAR artifact.

The Java source has not been compiled against Paper or tested in-game here.
